---
name: consolex-schedule
description: "Prepare a paused native Antigravity Automation using the task UUID and recurring schedule from ConsoleX."
---

The ConsoleX hook handles the explicitly typed command and supplies the setup result. Relay it. The owner enables the automation in Antigravity's Automations view. If the hook supplies no setup result, ask the owner to check the plugin and copy the schedule command from ConsoleX.
